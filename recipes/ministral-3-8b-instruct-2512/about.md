Ministral 3 8B Instruct is Mistral's instruction-tuned 8B language model with a 0.4B Pixtral vision encoder, with native tool calling and a 256k-token context. The export is made from Mistral's bf16 checkpoint ([mistralai/Ministral-3-8B-Instruct-2512-BF16](https://huggingface.co/mistralai/Ministral-3-8B-Instruct-2512-BF16)); the main repo holds FP8 weights. Mistral recommends a temperature below 0.1 for everyday and production use, so `generation_config.json` sets no sampling and runtimes decode greedily unless asked otherwise. See the [base model card](https://huggingface.co/mistralai/Ministral-3-8B-Instruct-2512) for capabilities, benchmarks and intended use.
