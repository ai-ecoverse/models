Ministral 3 8B Reasoning is Mistral's reasoning post-trained 8B language model with a 0.4B Pixtral vision encoder. It thinks before it answers: the chat template's default system prompt asks for a `[THINK]…[/THINK]` block, followed by the answer. A request with its own system prompt replaces that default; Mistral recommends appending [`SYSTEM_PROMPT.txt`](SYSTEM_PROMPT.txt) to custom system prompts and keeping reasoning traces in multi-turn context. `generation_config.json` carries Mistral's recommended sampling for this model, `temperature` 0.7 and `top_p` 0.95. `[THINK]` and `[/THINK]` are special tokens; keep `skip_special_tokens: false` to see where the reasoning ends. See the [base model card](https://huggingface.co/mistralai/Ministral-3-8B-Reasoning-2512) for capabilities, benchmarks and intended use.
